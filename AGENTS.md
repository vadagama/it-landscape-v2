# AGENTS.md

Правила для ИИ-агентов в этом репозитории. Прочитай перед любой задачей и следуй им; приоритет ниже только у явных инструкций пользователя в рамках его прав (см. «Ограничения»).

## Проект

**ИТ Ландшафт Small — «аналитики и UI»**: метамодель EA-каталога и дизайн-пакет интерфейса. Стадия ранняя: кода продукта ещё нет — есть BMad-инициатива (`_bmad-output/`: исследования, метамодель, дизайн экранов) и каркас дизайн-пакета (`design/`).

Язык работы — русский: документы, коммиты, тексты интерфейса (локаль по умолчанию `ru-RU`).

## Структура

| Путь | Что это | Правила |
|---|---|---|
| `design/` | Дизайн-пакет: спека `specs/`, доска `board/`, макеты `app/`, прототип `prototype/` | ведут дизайнеры, точка входа — `design/README.md` |
| `_bmad-output/` | Результаты BMad: инициатива, исследования, метамодель | часть репозитория, коммитить |
| `_bmad/` | Фреймворк BMad | в git не идёт; не править руками, обновляется установщиком |
| `.canvas/` | Канвас — инструмент доски (клон вне git) | в git не идёт |
| `.claude/` | Локальные настройки Claude Code | в git не идёт |

Подробности про дизайн-пакет, прототип и передачу в разработку — `design/README.md`.

## Задачи по дизайну (экраны, UI, макеты)

1. Начинай с навыка `canvas-start` — он обновит канвас, соберёт контекст и заведёт ветку.
2. Перед сборкой, правкой или ревью экрана загрузи навык `canvas-ui-rules`.
3. Правки `design/` — только в ветке `design/<задача>` и через PR в основную ветку.
4. Доску `design/board/canvas.json` правь только через канвас (`python3 .canvas/board.py …`); сгенерированные `board/SCREENS.md` и `board/changelog.json` руками не правь.
5. Коммиты веток `design/*` проходят проверки дизайн-пакета (pre-commit): не обходи их `--no-verify`.
6. Конфликт в `design/board/*.json` руками не чини — это работа канваса; попроси дизайнера слить ветки у себя.

## Задачи по продукту и аналитике (BMad)

- Результаты пиши в `_bmad-output/` и коммить: это единственная часть BMad, которая живёт в git.
- Вопросы по BMad, статусу инициативы и «что делать дальше» — навык `bmad`.

## Команды

```bash
# макеты (веб) — из design/app
cd design/app && npm ci
npm run dev          # разработка
npm run typecheck    # типы
npm test             # тесты

# мобильные макеты
npx expo start

# доска канваса
python3 .canvas/board.py serve
```

Проверки дизайн-пакета (`gates`, `gatesFull`, самопроверка экрана) описаны в `design/canvas.config.json`.

## Ограничения

- Секреты и окружение (`.env*`) в git не попадают; `node_modules/` и сборки ставятся заново (`npm ci`) — см. `.gitignore`.
- Не трогай `design/` из задач, не связанных с дизайном; правка контрактов из твоей ветки — отдельным PR и с предупреждением дизайнерам.
- Канвас пишет в git продукта только `design/` — код, `.gitignore`, `AGENTS.md` и настройки агентов ему не принадлежат.
- Коммить только то, что просил пользователь; ветки и PR — по правилам раздела «Задачи по дизайну».
