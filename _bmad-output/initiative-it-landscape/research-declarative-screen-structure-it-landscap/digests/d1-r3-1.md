### Inventory list & table UX (primary docs, S4)
- The Inventory is LeanIX's central repository; all architectural object categories (Application, Business Capability, Project, etc.) are stored as individual Fact Sheets; by default only Fact Sheets with "Active" status are listed; deleted ones move to "Archived" status under a trash-bin filter and archived Fact Sheets never count against the edition's Fact Sheet quota — LeanIX Product Documentation, ~2021-04 (page "updated about a month ago"; Wayback capture 2021-05-15), accessed 2026-10-04 — https://web.archive.org/web/20210515162240/https://docs.leanix.net/docs/find-fact-sheets-in-the-inventory — high — doc
- The Inventory has a Table View: toggle "As Table" in the upper right corner; by default it shows only name and type; a "Select columns" dropdown lists all information available on the selected Fact Sheet Type; per-category eye-icons make columns visible; categories can be dragged inside the menu to define column order; panel closed with a close button; the table view can be exported to Excel via the Export feature — LeanIX Product Documentation, ~2021-04 (capture 2021-05-15), accessed 2026-10-04 — https://web.archive.org/web/20210515162240/https://docs.leanix.net/docs/find-fact-sheets-in-the-inventory — high — pattern
- Search: a "smart search" (magnifier next to the filters) searches names, tags, categories and relations; a "Jump to a Fact Sheet" menu sits at the top of the page with matching strings underlined; unknown-name search narrows via filter options above the Fact Sheet List ("Dual Axis Filtering"); filter settings can be saved, and later cleared — LeanIX Product Documentation, ~2021-04 (capture 2021-05-15), accessed 2026-10-04 — https://web.archive.org/web/20210515162240/https://docs.leanix.net/docs/find-fact-sheets-in-the-inventory — high — pattern
- Inventory interactions: edit by double-clicking a section or via the Edit button on the right; Add button links related objects; "Delete entry" de-links without deleting; editing limited to admin and member roles, viewer can view and comment; an audit trail ("Last Update") shows all changes with user reference — LeanIX Product Documentation, ~2021-04 (capture 2021-05-15), accessed 2026-10-04 — https://web.archive.org/web/20210515162240/https://docs.leanix.net/docs/find-fact-sheets-in-the-inventory — high — doc
- Right sidebar of the Inventory hosts: "New Fact Sheet" (choose type, enter name, Create), "RECENTLY VIEWED" list, Delete Fact Sheet (with mandatory reason prompt), Clone (copies attributes, relations and documents; comments, surveys and metrics are not adopted), and Import functionality — LeanIX Product Documentation, ~2021-04 (capture 2021-05-15), accessed 2026-10-04 — https://web.archive.org/web/20210515162240/https://docs.leanix.net/docs/find-fact-sheets-in-the-inventory — high — doc

### Fact sheet detail anatomy (primary doc, S7)
- Fact Sheet detail page anatomy = Header + Body + Sidebar: Header shows name, type, tags, data-quality info and hosts subscribe, comments, documents, metrics, surveys and change history ("Last Update" section) plus basic actions (edit, print, delete, clone); Body holds all content (lifecycle, criticality, dependencies) "structured in sections"; Sidebar shows integrations active for that Fact Sheet, To-Dos, recently viewed Fact Sheets and related Diagrams — LeanIX Product Documentation, ~2021-06 (page "updated 9 days ago"; Wayback capture 2021-06-13), accessed 2026-10-04 — https://web.archive.org/web/20210613085421/https://docs.leanix.net/docs/what-is-a-factsheet — high — pattern
- Fact Sheet layout is template-per-type: every architectural object is stored in an individual template according to its Fact Sheet type (e.g., Data Object FS has a "Data Management" section; Project FS has "Project Environment" and "Project Setup" sections); Fact Sheet types are accessible on the upper left side of the Inventory — LeanIX Product Documentation, ~2021-06 (capture 2021-06-13), accessed 2026-10-04 — https://web.archive.org/web/20210613085421/https://docs.leanix.net/docs/what-is-a-factsheet — high — doc
- The standard meta model has ten main Fact Sheet types (Application, Data Object, Project, IT Component, Provider, Tech Category, User Group, Business Capability, Process, Interface) and "it is possible to configure the workspace to your needs" if standard definitions don't match — LeanIX Product Documentation, ~2021-06 (capture 2021-06-13), accessed 2026-10-04 — https://web.archive.org/web/20210613085421/https://docs.leanix.net/docs/what-is-a-factsheet — high — doc

### Views on reports (primary doc, S5)
- Reports carry a "View dropdown box" that color-codes Fact Sheets; a view can be based on: fields on the base Fact Sheet Type, fields on relations (e.g., Total annual cost lives on the Application–IT Component relation), fields on related Fact Sheets, or tags; tag colors are defined in the Administration section — LeanIX Product Documentation, ~2021-03 (page "updated 2 months ago"; Wayback capture 2021-05-15), accessed 2026-10-04 — https://web.archive.org/web/20210515170458/https://docs.leanix.net/docs/reporting-views — high — doc
- 14 standard report views shipped: Lifecycle (Plan/Phase in/Active/Phase out/End of Life), Functional Fit, Technical Fit, Business Criticality, Aggregated Obsolescence Risk, Project Risk, Project Status, Project Business Value (Budget OpEx+CapEx), Project Business Value (NPV), Provider Quality, Provider Criticality, IT Component/Application Total Annual Cost, Resource Classification, Data Classification — LeanIX Product Documentation, ~2021-03 (capture 2021-05-15), accessed 2026-10-04 — https://web.archive.org/web/20210515170458/https://docs.leanix.net/docs/reporting-views — high — number
- "Individualized views": users/admins can create their own attributes and tag groups and apply them as views in reports, next to the standard views — LeanIX Product Documentation, ~2021-03 (capture 2021-05-15), accessed 2026-10-04 — https://web.archive.org/web/20210515170458/https://docs.leanix.net/docs/reporting-views — high — pattern
