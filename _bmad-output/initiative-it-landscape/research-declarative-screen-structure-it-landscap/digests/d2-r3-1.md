- Dependency Map reference chains are strictly directional: incoming chains contain only incoming references; a direction change across degrees cannot be displayed and Ardoq recommends Block Diagram for that case; an interactive traversal simulation popover is attached to the info icon in the degrees dropdown — Ardoq Help, 2026-09-17, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44007-dependency-map — high — class: pattern
- Dependency Map data loading is workspace-scoped: "Ardoq only loads components which are directly referenced from a loaded workspace"; opening multiple workspaces yields more detailed multi-degree traversals — Ardoq Help, 2026-09-17, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44007-dependency-map — high — class: pattern
- Dependency Map interaction model: hover highlights all visible instances of a component; left-click navigates to that component (opens workspace if needed); right-click opens context menu; references sorted by direction (incoming first) → reference type → navigator sort → alphabetical — Ardoq Help, 2026-09-17, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44007-dependency-map — high — class: pattern
- Dependency Map perspectives: conditional formatting and reference labelling (e.g., show reference type as label on referenced components); color referenced components by a numeric field (example: total direct cost) — Ardoq Help, 2026-09-17, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44007-dependency-map — high — class: pattern
- Dependency Matrix doc (dated 2023-03-17): grid with source components on the left, targets along the top; left-click an intersection to create a reference, then select its properties; supports cross-workspace reference creation (choose source workspace in left menu, target workspace in top menu) and reference-type selection; positioned purely as mass reference creation — no analysis features described — Ardoq Help, 2023-03-17, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44002-dependency-matrix — high — class: doc
