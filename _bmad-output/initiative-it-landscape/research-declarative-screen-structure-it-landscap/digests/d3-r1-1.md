### Q3 — Ardoq

- Timeline view plots components as rows; date-range field values render as bars ("phases") and date fields render as milestone markers (diamonds); multiple date ranges on one component appear as distinct phases — Ardoq Help Center (article 44061), updated 2026-08-07, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44061-timeline-view — confidence high — class: doc
- Component relationships and reference groupings are listed hierarchically in the Timeline view; grouping rules control the hierarchy, and when grouping by reference the reference label is displayed on the timeline component (parent/child expand-collapse) — Ardoq Help Center, updated 2026-08-07, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44061-timeline-view — confidence high — class: doc
- Date-range fields are the metamodel primitive for lifecycle phases — the doc's example phase names are "Live, Review, and Phasing Out" for a project or an application's lifecycle — Ardoq Help Center, updated 2026-08-07, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44061-timeline-view — confidence high — class: pattern
- View controls: show/hide phases and milestones via pickers; explicit start/end date window for the timeline; layouts daily/weekly/monthly/quarterly/yearly with minimum date ranges (quarterly requires ≥1 year of data) plus auto-layout; Today button; zoom +/-; reset zoom; hover for detail — Ardoq Help Center, updated 2026-08-07, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44061-timeline-view — confidence high — class: doc
- Timeline is a configurable "view style" set in the Viewpoint Builder (Admin/Writer selects which date and date-range fields become milestones/phases and the visible date window for Discover users) — Ardoq Help Center, updated 2026-08-07, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44061-timeline-view — confidence high — class: doc
- Named use cases for Timeline view: Application Lifecycle Management, IT-lifecycle Management, Strategy To Execution — Ardoq Help Center, updated 2026-08-07, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44061-timeline-view — confidence high — class: doc
- Present mode exists as "Presentations": the help center contains "How to create and share a presentation" (updated 2026-02-18), "Presentation specific filters", "Keyboard shortcuts in presentation mode", iframe-embedding guides for Confluence (2025-11-13) and SharePoint (2025-02-12), and a video "Presentations: tips for better stakeholder engagement" (2025-10-30) — Ardoq Help Center sitemap (titles + lastmod), accessed 2026-10-04 — https://help.ardoq.com/sitemap.xml — confidence medium (existence/titles evidenced; article bodies not read) — class: doc
- Project/initiative-tracking and roadmap how-tos exist in the help center: "Effective Project Management: Examples of Using Time Filters in Ardoq" (2025-07-01), "Build application roadmaps using Ardoq scenarios" (2026-09-17), "How to automatically calculate component end dates and create a quarter-based roadmap" (2023-05-16), "Getting started with capability-based planning" (2026-02-26), "Modeling future states and transition architectures in Ardoq" (2026-05-27), "How to model your organization's as-is and to-be" (2025-07-01), "Jira Software Cloud integration" (2026-04-15) — Ardoq Help Center sitemap, accessed 2026-10-04 — https://help.ardoq.com/sitemap.xml — confidence medium — class: doc
