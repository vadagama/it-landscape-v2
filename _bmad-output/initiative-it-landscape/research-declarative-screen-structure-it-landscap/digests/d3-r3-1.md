### Ardoq Timeline view — mechanics and configuration (primary docs, high confidence)

- Timeline view mechanics: components as rows (vertical list or hierarchy per workspace/perspective/grouping); date-range field values render as bars (phases); date field values render as diamonds (milestones); multiple date ranges per component appear as distinct phases; parent components have expand/collapse — Ardoq Help, updated 2026-08-07, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44061-timeline-view — high — pattern
- Field setup: Admin/Writer create field types "Date Range" (renders as a phase; the field name is shown as the phase name) vs "Date" (renders as a milestone); values are entered via Grid Editor where a date range is a start+end pair — Ardoq Help, updated 2026-08-07, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44061-timeline-view — high — doc
- View configuration: show/hide phases and milestones via pickers; grouping rules control hierarchy and put reference labels on components; the visible window is set by an optional start/end date selector; layouts daily/weekly/monthly/quarterly/yearly with minimum windows (≥1 week / 1 month / 3 months / 1 year / 3 years) plus auto-layout; zoom +/-, Today button, hover detail — Ardoq Help, updated 2026-08-07, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44061-timeline-view — high — doc
- In Ardoq Discover, Timeline is configured as a viewpoint view style in the Viewpoint Builder: pick which date/date-range fields render as milestones/phases and cap the visible date window for Discover users — Ardoq Help, updated 2026-08-07, accessed 2026-10-04 — https://help.ardoq.com/en/articles/44061-timeline-view — high — doc
- Timeline view-style enhancements (June 2026): multiple configurable component labels (chosen from default/custom fields, ordered, field names shown/hidden per component type, >2-line truncation with hover tooltip, dividers), saved as part of the viewpoint; expand/collapse for labels, hierarchy children, and groups; hover highlights the row, click applies sticky highlight; reference labels are saved but not displayed — Ardoq Help, updated 2026-06-16, accessed 2026-10-04 — https://help.ardoq.com/en/articles/283837-timeline-view-view-style — high — doc
