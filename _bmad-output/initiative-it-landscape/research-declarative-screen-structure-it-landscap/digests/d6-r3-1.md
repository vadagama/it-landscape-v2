- Below the main ranked list an expandable "Other results" section holds matches ranked under the relevance threshold — Ardoq Help, 2026-07-08, https://help.ardoq.com/en/articles/682139 — high — pattern

- ID-first search: typing an exact Ardoq component key, or a value of the admin-designated "custom search field" (e.g. external system ID / cost centre code), pins the match to the top of results ahead of all semantic matches; both are case-insensitive and work with partial values — Ardoq Help, 2026-07-08, https://help.ardoq.com/en/articles/682139 — high — pattern
