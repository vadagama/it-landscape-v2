# D1 r1 — Standards & landscape (assistant 1, round 1)

Method note: budget exhausted 15/15 tool calls, 8 distinct sources read. BIZBOK page confirmed member-gating (itself a finding).

## Questions

1. ArchiMate (current version — task assumed 3.2): layers/views; element types per layer; relation types + semantics; extension mechanism (viewpoints, customization)?
2. TOGAF 10 Content Metamodel: core entities/relations; coexistence/mapping with ArchiMate; official "minimal core"?
3. BIZBOK / Business Architecture Guild: entity vocabulary (capability, value stream, organization, information…); public vs license-gated?
4. Landscape: layered vs property-graph vs hybrid metamodels; what modern EAM tooling adds beyond classic standards (first-class relations, versioned states, graph tech, time travel)?
5. Practitioner criticism of standard metamodels?

## Findings

**Version / freshness (key correction)**
- ArchiMate Specification's latest version is 4, released April 2026 — the task's "likely 3.2" assumption is outdated; spec access is license-gated (member license, free 90-day evaluation, free perpetual non-commercial, paid annual commercial) — The Open Group, n.d., accessed 2026-10-04, https://www.opengroup.org/archimate-licensed-downloads — confidence: high — class: standard
- The formerly public online spec at pubs.opengroup.org (ArchiMate 3.2 index and chapter URLs) now redirects to an Open Group sign-in wall — accessed 2026-10-04 — confidence: high — class: failure
- Wikipedia's ArchiMate article, even after a 2026-07-13 edit, still lists 3.2 (Oct 2022) as latest — tertiary sources lag the primary; version claims must come from opengroup.org — Wikipedia, 2026-07-13, accessed 2026-10-04, https://en.wikipedia.org/wiki/ArchiMate — confidence: medium — class: doc

**Q1 ArchiMate (from Wikipedia, secondary — spec itself gated)**
- Core framework = 3 layers (business, application, technology) × 3 aspects (active structure, behavior, passive structure); full framework adds strategy layer (resource, capability, course of action), physical layer, implementation & migration layer, and a motivation aspect (stakeholder, value, driver, goal, meaning) — Wikipedia, 2026-07-13, accessed 2026-10-04, https://en.wikipedia.org/wiki/ArchiMate — confidence: medium — class: standard (needs 2nd source; exact 4.x inventory unverifiable behind gate)
- Layer semantics: higher layers consume lower layers' services via "use" relations; "realisation" runs upward (data object realises business object; artifact realises data object / application component) — Wikipedia, 2026-07-13, accessed 2026-10-04, https://en.wikipedia.org/wiki/ArchiMate — confidence: medium — class: standard (needs 2nd source)
- Relationships are grouped structural / dependency / dynamic / other; only "use" and "realisation" are explicitly named in this source; full relation list not retrievable — Wikipedia, 2026-07-13, accessed 2026-10-04, https://en.wikipedia.org/wiki/ArchiMate — confidence: medium — class: standard (needs 2nd source)
- Views/viewpoints are the standard's tailoring mechanism: a view addresses related concerns for specific stakeholders; concepts are deliberately separated from notation — Wikipedia, 2026-07-13, accessed 2026-10-04, https://en.wikipedia.org/wiki/ArchiMate — confidence: medium — class: standard
- Deliberate smallness: ~50 concepts in v2.0 vs ~150 (UML) and ~250 (BPMN); design goal "the proverbial 80% of practical cases" — Wikipedia, 2026-07-13, accessed 2026-10-04, https://en.wikipedia.org/wiki/ArchiMate — confidence: medium — class: number (needs 2nd source)
- Element names appear in the article only in passing (partial inventory): business actor, role, interface, collaboration, business object, data object, artifact, application component, device — Wikipedia, 2026-07-13, accessed 2026-10-04, https://en.wikipedia.org/wiki/ArchiMate — confidence: low — class: standard (needs 2nd source)
- v3.0 added capability-oriented strategic modeling, physical-resource entities, and a generic metamodel of entity types + relationships; model exchange is an XML/XSD format intended for exchange, not persistence — Wikipedia, 2026-07-13, accessed 2026-10-04, https://en.wikipedia.org/wiki/ArchiMate — confidence: medium — class: standard
- ArchiMate 3.2 (Oct 2022) was a "pilot program" between the ArchiMate Forum and the user community — snippet-only via earlier search, accessed 2026-10-04 — confidence: low — class: standard (needs 2nd source)
- The Open Group South Africa's ArchiMate 3.2 page is marketing register: audience description and a TOGAF 10 integration narrative (shared vocabulary, ADM↔multi-layer alignment, ArchiMate visualizes TOGAF concepts) but zero element/relation/layer detail — The Open Group South Africa, © 2023, accessed 2026-10-04, https://www.opengroup.co.za/archimate-standard-32 — confidence: medium — class: doc

**Q2 TOGAF Content Metamodel**
- TOGAF Standard, 10th Edition launched 25 April 2022 — Wikipedia (citing Open Group announcement), 2026-06-24, accessed 2026-10-04, https://en.wikipedia.org/wiki/TOGAF — confidence: medium — class: standard (needs 2nd source)
- A formal Content Metamodel linking TOGAF artifacts was introduced with TOGAF 9; the article notes "some problems with the Metamodel" — Wikipedia, 2026-06-24, accessed 2026-10-04, https://en.wikipedia.org/wiki/TOGAF — confidence: low — class: standard (needs 2nd source)
- TOGAF models four levels/domains: Business, Data, Applications, Technology; TOGAF is free for internal non-commercial use — Wikipedia, 2026-06-24, accessed 2026-10-04, https://en.wikipedia.org/wiki/TOGAF — confidence: medium — class: standard

**Q3 BIZBOK**
- The BIZBOK Guide is member-gated: "you must first register and be approved before accessing many site sections including member-only resources and the BIZBOK® Guide" — Business Architecture Guild, © 2024, accessed 2026-10-04, https://www.businessarchitectureguild.org/page/BIZBOK — confidence: high — class: failure
- Publicly visible is structure only: Quick Guide (sold via store), Publications, Whitepapers, Case Studies, Industry Reference Models, certification program, GATP tool registry; no entity vocabulary (capability, value stream, etc.) is publicly retrievable — Business Architecture Guild, © 2024, accessed 2026-10-04, https://www.businessarchitectureguild.org/page/BIZBOK — confidence: medium — class: doc

**Q4 Landscape**
- Open Group-certified TOGAF tool register (TOGAF 9.x, renewals into 2026–2028): Avolution ABACUS, Bizzdesign Enterprise Studio/Hopex/Alfabet/Horizon, BOC Group ADOIT, Orbus iServer, Software AG ARIS — i.e., the incumbent certified-tool set remains layered/EPM-tool vendors — Wikipedia, 2026-06-24, accessed 2026-10-04, https://en.wikipedia.org/wiki/TOGAF — confidence: medium — class: practice (needs 2nd source; register is TOGAF 9-era, not refreshed for TOGAF 10)

**Q5 Criticism**
- Motivation-extension concepts found "confusing and/or duplicative" per peer-reviewed research (Azevedo et al. 2011 ontology-based semantics; Engelsman & Wieringa 2012/2014 understandability studies; Nardi et al. 2014 ontological analysis of business-layer services) — Wikipedia, 2026-07-13, accessed 2026-10-04, https://en.wikipedia.org/wiki/ArchiMate — confidence: medium — class: practice (needs 2nd source)
- Business-layer concepts are "less tangible"/"ill-defined" — echoed by ArchiXL's "Three common limitations of ArchiMate" (Oord, 2014) — Wikipedia, 2026-07-13, accessed 2026-10-04, https://en.wikipedia.org/wiki/ArchiMate — confidence: medium — class: practice (needs 2nd source)
