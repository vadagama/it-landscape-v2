**Q2: Relation types**
- Relation keys encode direction explicitly: `relApplicationToITComponent` (application → IT component) vs `relITComponentToApplication`; "The relation key reflects the direction of the relation" — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/fact-sheet-relations — confidence: high — class: doc
- Official semantic examples: "a business capability is supported by an application", "an application runs on an IT component", "an organization uses an application", "an application interfaces with another application" — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/meta-model — confidence: high — class: doc
- Relation multiplicity is first-class and typed: many-to-many, one-to-many, many-to-one, one-to-one; multiplicity is immutable once set — for custom AND predefined relations — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/fact-sheet-relations — confidence: high — class: doc
- Parent-child is a universal relation (target = all fact sheet types); such relations cannot be deleted; max hierarchy depth configurable per type — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/fact-sheet-relations and https://help.sap.com/docs/leanix/ea/meta-model-configuration — confidence: high — class: doc
- Two protected relation classes cannot be deleted: constraining relations (relation constrained by / constrains another) and relations used in naming rules — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/fact-sheet-relations — confidence: high — class: doc
- Relations carry their own fields (edge attributes); example: application cost captured on the application–IT component relation — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/fact-sheet-relations and https://help.sap.com/docs/leanix/ea/application-modeling-guidelines — confidence: high — class: doc
- Custom relations between any fact sheet types supported; when multiple relations exist between same pair, disambiguating descriptor appended to relation key — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/fact-sheet-relations — confidence: high — class: doc
- Self-referencing relations supported (source and target of same type, including subtypes of one type); conditional relations between subtypes controlled by conditional attributes — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/fact-sheet-relations — confidence: high — class: doc
- No single official textual relation matrix exists in current docs; official artifacts are per-type "Overview of All Relations to and from X" images in modeling-guidelines pages plus downloadable meta-model XML — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/meta-model — confidence: high — class: failure

**Q3: Field structure**
- Fact sheet body: sections → subsections → fields (plus header); order and visibility admin-configurable; deleting a non-empty section moves contents to "Unused Fields and Relations" (hidden, data intact, API-accessible) — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/meta-model-configuration — confidence: high — class: doc
- Official field types: Double, Integer, Multiple Select, Single Select, String, External Id, Base Field; only first six available for custom fields; some fields use non-configurable special types (e.g., Lifecycle, Project Status) — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/fact-sheet-fields — confidence: high — class: doc
- Each field has unique, immutable key (technical name) used by integrations/APIs; custom attribute keys must begin with a letter; Single/Multiple Select option IDs too — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/fact-sheet-fields — confidence: high — class: doc
- Field type immutable once created; display format type-determined; width XS–XXL; no hard character limit but >32,766 characters "may lead to incorrect behavior" — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/fact-sheet-fields — confidence: high — class: doc (needs 2nd source for 32,766 limit)
- Required vs optional operationalized through per-type completion score with configurable completion weights; per-type field sets and modeling guidance live in per-type Modeling Guidelines pages — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/meta-model-configuration — confidence: high — class: doc
- Conditional attributes make fields/relations visible only when condition field values met; per-field label/help-text translations with AI support — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/meta-model-configuration — confidence: high — class: doc
- Deleting fields or field values temporarily sets workspace read-only (typically ≤15 minutes) — SAP, n.d., accessed 2026-10-04, https://help.sap.com/docs/leanix/ea/fact-sheet-fields — confidence: high — class: doc

**Q4: Extensibility**
