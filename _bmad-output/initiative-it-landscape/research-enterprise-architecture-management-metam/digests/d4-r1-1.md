**Technical build (Q3)**
- Open source Essential is "based on a forked version of Protege from Stanford University that the Essential Project maintains" — EAS, 2024-04-26, accessed 2026-10-04, https://enterprise-architecture.org/university/open-source-overview/ — confidence: high — class: doc (verifies Protege, refutes Eclipse/EMF as repository basis)
- The meta model itself is "a tree hierarchy of Classes and Slots": Classes define element types, Slots define attributes — EAS, 2024-01-22, accessed 2026-10-04, https://enterprise-architecture.org/university/extending-the-essential-meta-model/ — confidence: high — class: doc (Protege frames vocabulary confirmed in current docs)
- Open source and Cloud/Docker share the same meta model; migration between them "in a few minutes"; open source uses a Java-based capture front-end and a Protege server for multi-user; simple API only — EAS, 2024-04-26, accessed 2026-10-04, https://enterprise-architecture.org/university/open-source-overview/ — confidence: high — class: doc
- Cloud/Docker-only capabilities: REST APIs, Essential Editors (API-dependent), in-view repository updates; Protege file import/export available for the repository — EAS, 2024-04-26, accessed 2026-10-04, https://enterprise-architecture.org/university/open-source-overview/ — confidence: high — class: doc (needs 2nd source for Protege import/export detail beyond docs nav)

**ArchiMate (Q4)**
- Essential Cloud/Docker ships an "Open Exchange XML Data Loader": loads Open Exchange XML "e.g. from ArchiMate®" exported from the Archi tool, with a visual mapping of Archi concepts → Essential classes (default mappings provided, editable and persistable) and a relations panel that auto-creates "a number of key relationships" — EAS, 2023-12-09, accessed 2026-10-04, https://enterprise-architecture.org/university/open-exchange-xml-data-loader-cloud-docker/ — confidence: high — class: doc
- This is a one-way import loader, not a live mapping/synchronization; no ArchiMate export or sync documentation found — EAS, accessed 2026-10-04, https://enterprise-architecture.org/university/open-exchange-xml-data-loader-cloud-docker/ — confidence: medium — class: doc

**Extensibility (Q5)**
- Two documented extension mechanisms: (1) add new Classes/Slots directly via Configure→Class Editor; (2) apply an Essential Update Pack (EUP) — "a script that encodes the changes to the meta model", applicable to multiple repositories, excluding Cloud form layout and custom labels — EAS, 2024-01-22, accessed 2026-10-04, https://enterprise-architecture.org/university/extending-the-essential-meta-model/ — confidence: high — class: doc
- Official recommendation: extend by adding new elements rather than changing out-of-the-box meta model elements; form layout (slot ordering/grouping) and custom form labels configurable per class — EAS, 2024-01-22, accessed 2026-10-04, https://enterprise-architecture.org/university/extending-the-essential-meta-model/ — confidence: high — class: practice
- Official adoption playbook treats "Identify any Meta Model extensions required and the impacts" as a standard step — EAS, n.d., accessed 2026-10-04, https://enterprise-architecture.org/university/how-to-be-successful-with-essential/ (docs nav) — confidence: medium — class: practice (needs 2nd source)

**Licensing/openness (Q6)**
- Commercial: Essential Cloud "from just $27,999 per year", unlimited users (official pricing claim) — EAS, n.d. (site © 2026), accessed 2026-10-04, https://enterprise-architecture.org/ — confidence: high (official), register-style number — class: number (needs 2nd source)
- Open source edition downloadable, shares the meta model with paid product (same ontology, most views, import utility); paid editions add REST APIs and Editors — EAS, 2024-04-26, accessed 2026-10-04, https://enterprise-architecture.org/university/open-source-overview/ — confidence: high — class: doc
- Specific open-source license terms (which license the forked Protege carries) not verified this run — confidence: low — class: doc
