## Patterns worth adopting (round-2 synthesis, preserved as structured output)

1. **Namespacing** — extension keys carry an owner prefix; one namespace reserved for the platform (Backstage annotations; K8s label keys; SCIM URN extensions).
2. **Additive-only evolution** — extensions may add, never redefine core (SCIM extension rule).
3. **Graduation path** — extension concepts move through stability grades (K8s alpha→beta→GA; Backstage `apiVersion` v1alpha1→v1beta2).
4. **Extension registry** — central, discoverable registry of approved extensions (IANA schema URN registry; LeanIX Extension Hub).
5. **Versioned change scripts + sandbox** — metamodel changes ship as versioned scripts applied to a snapshot of the model (Essential EUP + snapshot-before-apply; EUP/DUP release channels).
6. **One-way constraint relaxation** — governance can be loosened irreversibly, never silently tightened (Ardoq rigid→flexible one-way conversion; Ardoq constraints ladder Off/Guided/Strict).
7. **Start small** — minimal prescriptive core, grow on demand (Ardoq Principles 1 & 4; LeanIX prescriptive v4 core; Backstage 9 kinds).
8. **Packaged verticals on a shared core** — use-case templates bundle metamodel fragments + fields + views on top of the core (Ardoq Solutions ×27; LeanIX use cases; Essential Launchpad Plus).
