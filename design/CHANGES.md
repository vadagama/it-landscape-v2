# Изменения для разработки

дизайнеров (`canvas-handoff`): сначала сводка дизайнера своими словами, затем по доске и git — экраны, состояния,
переходы, контракты, свои компоненты с новыми версиями и открытые замечания. Кадры — по ссылкам в `board/`, прототип — `prototype/index.html`
(открывается двойным щелчком).
