# contracts — что экраны читают и вызывают

Типы сущностей (`entities.ts`) и интерфейсы экранов (по паре `XQuery`/`XActions` на экран), собранные в `provider.ts`. Без React и без сети: этот каталог вместе с примерами из `mocks/` уходит программистам — `board.py handoff` кладёт его в `design/board/HANDOFF.md`. Правило: поле, которое видно на экране, есть в сущности; метод, который вызывает кнопка, есть в интерфейсе; имя метода совпадает с `agent.data` узла доски. Подробнее — `design/specs/02-data-contracts.md`.
