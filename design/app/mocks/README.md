# mocks — наборы фикстур

Каждый каталог — один сценарий для проверки гипотезы («пусто», «10 записей», «ошибка»), файлы — по сущностям. Реестр — `index.ts` (статические `import`: сборщик должен видеть файлы заранее). На доске наборы — состояния экрана: слой узла — тот же экран на другом наборе. Замена на свои данные: положить каталог, зарегистрировать в `index.ts`, переключить (`design/specs/02-data-contracts.md` §5). Набор при запуске — переменная сборки `VITE_MOCK_SET` (`VITE_MOCK_SET=empty npm run dev`), без неё — `default`.
