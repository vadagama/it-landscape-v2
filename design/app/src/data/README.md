# src/data — шов данных приложения

`context.tsx` — провайдер для экранов: `DataRoot` в корне приложения, `useData()` в экране; экраны не импортируют `mocks/` напрямую. `mockSet.ts` — какой набор моков активен (сохранённый выбор → переменная сборки → набор по умолчанию) и как его переключить (`selectMockSet`); `createMockProvider.ts` — реализация `contracts/provider.ts` поверх фикстур. Когда появится API, вместо `createMockProvider` в `context.tsx` встаёт его реализация с теми же интерфейсами.
