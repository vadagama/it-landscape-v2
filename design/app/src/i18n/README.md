# src/i18n — словари переводов

Словарь языка — `<язык>.json` (`en.json`, `kk.json`): ключ — фраза базового языка, как она написана в коде (`t('Главная')`), значение — перевод целиком, с теми же подстановками `{имя}`. Новый язык: положите словарь сюда, подключите его в `DICTIONARIES` (`src/i18n.ts`) и объявите язык на доске (`capture.dimensions.locale`); сторож переводов `board.py langcheck` сверит словарь с кодом и кадрами. Правила перевода — навык `canvas-ui-rules`, `rules/i18n.md`.
