# 00 — Видение

Одна фраза о продукте: кто им пользуется и какую работу делает.

## 1. Для кого и зачем

- **Пользователь:** кто работает с приложением каждый день и в каких условиях (устройство, шум, спешка).
- **Задача:** какую работу он хочет сделать; чем плохо сейчас.
- **Мера успеха:** одна-две метрики, по которым ясно, что продукт сработал.

## 2. Ключевые сценарии

По одному абзацу на сценарий: откуда пользователь входит, через какие экраны идёт, чем заканчивает. Эти сценарии — дорожки доски (`flows` в `design/board/canvas.json`).

## 3. Принципы

- Дизайн как код: экран существует только как компоненты кита, утверждается на доске и уходит дальше как есть.
- Данные через контракты: экран не знает, откуда данные; наборы моков — сценарии для проверки гипотез.
- Проверка на людях: сборка с выбранным набором моков ставится респондентам без бэкенда.

## 4. Не-цели

Что сознательно не делается в этой версии.
