# 02 — Контракты данных и моки

Экраны it-landscape-v2 не знают, откуда берутся данные: они читают их только через **контракты** — интерфейсы запросов и действий каждого экрана — а провайдер этих контрактов подменяется. Пока бэкенда нет, провайдер отдаёт **фикстуры** из `mocks/<набор>/`; на доске наборы моков — это `states`, а слои узла — тот же экран на другом наборе. Когда бэкенд появится, он реализует те же интерфейсы, и экраны не меняются. Именно это уходит на реализацию бэкенда: `contracts/` + примеры из `mocks/` + спека экранов. Пути ниже — от каталога макетов (`app.dir` конфига дизайн-пакета; у заготовки канваса — `design/app/`).

## 1. Сущности

`contracts/entities.ts` — типы предметной области (без React, без сети). Каждое поле, которое видно на экране, есть здесь.

## 2. Интерфейсы экранов

По паре интерфейсов на экран: `XQuery` (что экран читает) и `XActions` (что вызывает). Имена методов — те же, что в `agent.data` узла доски (`{"reads": ["OrderQueueQuery.listOrders"], "actions": ["OrderQueueActions.claimOrder"]}`), сторож проекта сверяет их существование.

## 3. Наборы моков

`mocks/<набор>/*.json` — фикстуры одного сценария («10 заказов», «пустая смена», «ошибка сети»). Реестр наборов — `mocks/index.ts` (статические `require`, иначе сборщик их не увидит). Набор описывает **сценарий для проверки гипотезы**, а не «все данные».

## 4. Переключение набора

Три входа, один шов `src/data/mockSet.ts`: переменная сборки (`EXPO_PUBLIC_MOCK_SET=<набор>`), скрытый экран «Сценарий» на стенде прототипа, deep link `<scheme>://mock/<набор>`. Выбор сохраняется на устройстве; рецепт состояния доски открывает deep link и запускает приложение.

## 5. Как заменить моки на свои данные

1. Положить свой набор в `mocks/<имя>/` теми же файлами и зарегистрировать в `mocks/index.ts`.
2. Собрать или переключить приложение на этот набор (§4) — экраны и прототип на доске подхватят его без правок кода.
3. Когда появится бэкенд — реализовать `contracts/provider.ts` поверх API и включить его вместо `createMockProvider` в `src/data/`.
